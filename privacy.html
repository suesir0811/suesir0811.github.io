「歐膩539上傳」（以下稱「本應用程式」）是「歐膩今彩539」頻道經營者自用的內部工具，只用來把我們自己製作的每日短影片上傳到我們自己的 YouTube 頻道。本應用程式不對外開放，也不提供給其他使用者登入。

一、本應用程式使用 YouTube API 服務

本應用程式透過 YouTube API 服務上傳影片。使用本應用程式即表示同意遵守 YouTube 服務條款。 Google 如何處理資料，請參閱 Google 隱私權政策。

二、我們存取哪些資料

本應用程式只要求「上傳影片到授權帳號的 YouTube 頻道」的權限（youtube.upload），用來上傳影片並設定標題、說明與公開狀態。我們不讀取觀眾資料、留言、訂閱者名單或任何其他使用者的個人資料。

  • 授權憑證（存取權杖）只儲存在頻道經營者自己的電腦上，用於每日自動上傳。

  • 我們不使用 Cookie，也不在本應用程式中收集瀏覽紀錄。

四、撤銷授權與刪除資料

授權帳號可隨時到 Google 帳戶的第三方存取權限頁面 撤銷本應用程式的存取權。撤銷後，我們會刪除本機儲存的授權憑證。如需刪除任何相關資料，請來信聯絡我們，我們會在 7 天內處理。
